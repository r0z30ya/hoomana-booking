# ساختار UX — هومانا (مرحلهٔ ساختار، نه طراحی بصری)

- **وضعیت:** سند زندهٔ طراحی — ساختار و جریان‌ها
- **تاریخ:** ۲۰ مهر ۱۴۰۵ (۱۲ اکتبر ۲۰۲۶)
- **منبع:** جلسهٔ طراحی با ایجنت «فرانت‌اند هومانا» بر پایهٔ `infra/docs/architecture.md` و ADR-0004
- **دلیل:** هویت اطلاعاتی محصول (نقش‌ها، حالت مطب/کلینیک، پورتال بیمار) تثبیت شده است؛ پس طراحی **ساختاری** الان به‌موقع است و از دوباره‌کاری جلوگیری می‌کند. طراحی **بصری** عمداً به بعد موکول شده (بخش ۵).
- **قاعدهٔ زبان:** رابط کاربری فارسی و راست‌به‌چپ؛ اعداد و تاریخ شمسی؛ منطق دامنه روی `Asia/Tehran`.

## ۲) جریان‌های کلیدی

1. **ثبت‌نام خودخدمت:** موبایل → رمز → ساخت مستاجر → اتصال پکیج رایگان (`TRIALING`) → onboarding کوتاه (خدمت، ساعت کاری، اولین نوبت).
2. **حالت مطب/کلینیک:** UI فقط از پرچم `tenants.type` (`SOLO | CLINIC`) تبعیت می‌کند — در `SOLO` هیچ انتخاب پزشکی در فرم، تقویم و فیلترها وجود ندارد؛ در `CLINIC` گام «انتخاب پزشک» و نمای حضور روزانه اضافه می‌شود.
3. **رزرو عمومی بیمار:** خدمت → (پزشک فقط در CLINIC) → تاریخ/اسلات شمسی → اطلاعات بیمار → **OTP** → تأیید.
4. **لیست بیماران پزشک:** تنظیم ساعت ارسال توسط OWNER؛ **پیش‌نمایش متن** قبل از ارسال؛ حالت لحظه‌ای با یک کلیک.
5. **ثبت تراکنش (درآمد/هزینه):** از داشبورد (دسترسی سریع)، ردیف هر نوبت (گزینهٔ «تراکنش» با پیش‌پر‌کردن بیمار/خدمت/نوبت و مبلغ از تعرفهٔ خدمت اگر دارد) یا صفحهٔ حسابداری → فرم تراکنش (نوع، مبلغ، تاریخ، بیمار اختیاری، توضیحات) → ذخیره → به‌روزرسانی نشانهٔ پرداخت نوبت و اعداد روز.
6. **جابجایی/کنسل نوبت نرسیده (اپراتور):** فقط برای نوبت‌های آینده (و امروز تا پیش از ساعت نوبت)؛ «جابجایی» = انتخاب اسلات آزاد جدید همان پزشک/خدمت؛ «کنسل» = خروج از نماهای فعال + پیامک «لغو نوبت»؛ نوبت گذشته فقط پرونده/تاریخچه دارد.

## ۳) اصول ثابت

- فارسی/RTL، اعداد و تقویم شمسی، موبایل‌اول (ناوبری پایین).
- دسترس‌پذیری: فوکوس مشخص، برچسب فیلدها، کنتراست کافی.
- پیام خطای فارسی و صریح، کنار همان فیلد (نه فقط Toast).
- **هیچ‌وقت `tenant_id` از سمت کلاینت به‌عنوان مرجع** — مستاجر از Hostname تشخیص داده می‌شود.

## ۴) اجزای پایهٔ `apps/web` (پیش از صفحه‌سازی)

`AppShell` و ناوبری نقش‌آگاه، `AuthGuard`، شکل‌دهندهٔ تاریخ/عدد شمسی، `DatePicker` شمسی، `DataTable`/لیست، فرم با Zod، `OTPInput`، Modal/Drawer، Toast، EmptyState، حالت‌های بارگذاری/خطا.
