# مرجع سبک طراحی — هومانا

- **وضعیت:** تصویب‌شدهٔ مالک (۲۰۲۶-۱۰-۱۲) — مبنای هویت بصری `apps/web`
- **منبع:** `panel.html` (پنل کامل) و `login.html` (صفحهٔ ورود) — نمونه‌های ایستای HTML/CSS تأییدشدهٔ مالک
- **مخاطب:** هر کسی (یا هر ایجنتی) که صفحه‌ای از `apps/web` را می‌سازد

> ⚠️ فایل‌های HTML مرجع، نمونهٔ ایستا هستند (Tailwind از CDN، بدون فریم‌ورک). در محصول واقعی همین زبان طراحی با **CSS Variables واقعی** پیاده شده است (`apps/web/src/styles/theme.css` بدون Tailwind)؛ این فایل‌ها مرجعِ «شکل نهایی»اند، نه کد قابل استفاده.

## ۱) هویت در یک نگاه

سبک **نئومورفیسم گرم** روی پس‌زمینهٔ بژ/فحمی، با اکسنت فیروزه‌ای (Teal)، کاملاً RTL، فونت **Vazirmatn**، و تم روشن/تیره با متغیرهای CSS.

## ۳) کلاس‌های پایه (زبان نئو)

| کلاس | تعریف | کاربرد |
|---|---|---|
| `neu` | سایهٔ دوطرفهٔ `9px 9px 20px` تیره + `-9px -9px 20px` روشن | کارت‌ها، پنل‌های اصلی |
| `neu-sm` | همان با `5px/12px` | دکمه‌های کوچک، کارت ورود |
| `neu-in` | سایهٔ داخلی (`inset 5px 5px 10px`) | فیلد ورودی، ساعت نوبت، حالت فعال ناوبری |
| `lift` | hover: بالا آمدن `translateY(-3px)` + سایهٔ بیشتر | کارت‌های آمار |
| `press` | active: فرورفتن (سایهٔ inset) | دکمه‌های قابل فشار |
| `cta` | گرادیان teal + سایهٔ رنگی | دکمهٔ اصلی عمل |
| `fld:focus-within` | inset + حلقهٔ داخلی teal | فوکوس فیلد ورودی |
| `cbx` | چک‌باکس سفارشی (inset، تیک گرادیانی) | «مرا به خاطر بسپار» |
| `shake` | انیمیشن لرزش ۰.۴ ثانیه | خطای اعتبارسنجی فرم |

**قاعدهٔ کلی:** مرز (border) استفاده نمی‌شود — همه چیز با سایه و عمق ساخته می‌شود؛ گردی‌ها بزرگ‌اند (۱۶ تا ۳۶ پیکسل).

## ۴) اجزای شناسایی‌شده در نمونه‌ها

- **سایدبار راست** (۲۶۴px، فقط دسکتاپ): لوگو «هـ» گرادیانی، ناوبری با آیکون‌های خطی، کارت کاربر پایین
- **نوار بالا**: جستجوی `neu-in`، دکمهٔ تم روشن/تیره (خورشید/ماه)، زنگ اعلان با نقطهٔ کهربایی
- **داشبورد**: کارت‌های آمار (عدد درشت `font-black` + pill درصد)، «برنامهٔ امروز» (ساعت در `neu-in` + آواتار + pill وضعیت)، نمودار ستونی هفته (ستون امروز = گرادیان teal)
- **نوبت‌ها**: نوار روزهای هفته (`neu-in` با نقطهٔ وضعیت)، چیپ‌های فیلتر (`chip`/`chip.active`)، ردیف‌های نوبت با اکشن‌های تأیید/لغو، صفحه‌بندی
- **بیماران**: جدول با آواتار گرادیانی + جنسیت/سن، pill وضعیت بیمار، جستجو با چیپ‌های گروه
- **حسابداری**: دکمهٔ «گزارش اکسل» (نیازمندی ایمپورت/گزارش مالک را یادآوری می‌کند)
- **موبایل**: ناوبری پایینی (`mnav`)، پدینگ پایین صفحه
- **صفحهٔ ورود** (`login.html`): لوگوی SVG با انیمیشن خط ضربان و ضربان در hover، فیلد با آیکون و حلقهٔ فوکوس teal، دکمهٔ نمایش/مخفی رمز، چک‌باکس سفارشی، جداکنندهٔ «یا» + دکمهٔ «ورود با کد پیامکی»، لرزش فرم در خطا، دکمهٔ تم زیر کارت

## ۵) اصول ثابت (هم‌راستا با سند UX)

1. فارسی/RTL کامل، فونت Vazirmatn با وزن‌های ۳۰۰–۹۰۰
2. تم روشن/تیره فقط با جابه‌جایی `data-theme` روی `<html>` — هیچ رنگ hardcoded در کامپوننت‌ها
3. موبایل-اول: سایدبار در دسکتاپ، ناوبری پایینی در موبایل
4. عمق نرم به جای مرز؛ گردی بزرگ؛ اعداد درشت `font-black` برای آمار
5. حالت‌های وضعیت همیشه با pill رنگی (نه فقط متن)
6. بک‌گراند: دو دایرهٔ محو (`glow`) با blur برای عمق فضایی
