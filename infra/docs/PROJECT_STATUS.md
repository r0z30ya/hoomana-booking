# گزارش وضعیت پروژه هوومانا

آخرین به‌روزرسانی: ۱ نوامبر ۲۰۲۶

این فایل برای ادامه توسعه پروژه و جلوگیری از تکرار کارهای انجام‌شده نگهداری می‌شود.

## معرفی پروژه

هوومانا یک SaaS چندمستاجری برای نوبت‌دهی و مدیریت کلینیک‌ها است. هر کلینیک یک tenant مستقل دارد و پلتفرم می‌تواند برای هر tenant دامنه اختصاصی، تنظیمات پیامک و اشتراک جداگانه نگهداری کند.

## معماری فعلی

- Monorepo مبتنی بر npm workspaces
- API: Fastify + TypeScript
- Web: React + Vite + TypeScript
- Database: PostgreSQL + Prisma 7 + `@prisma/adapter-pg`
- Cache/queue زیرساختی: Redis
- جداسازی tenantها با PostgreSQL RLS
- نقش‌های دیتابیس: `hmn_migrator`، `hmn_app` و `hmn_platform`
- مسیر پنل پلتفرم: `admin.localhost:3000`
- مسیر API محلی: `127.0.0.1:3001`

## قابلیت‌های انجام‌شده

### هویت و دسترسی

- ورود کاربران با موبایل و رمز عبور
- نشست امن با cookie سمت سرور
- MFA مدیر پلتفرم با TOTP
- کدهای بازیابی یک‌بارمصرف
- محدودسازی تلاش‌های ناموفق ورود
- لغو نشست در صورت تعلیق یا مسدود شدن tenant

### پنل مدیریت پلتفرم

- مشاهده همه اکانت‌ها و کلینیک‌ها
- جست‌وجوی اکانت بر اساس نام، slug، مالک، موبایل و شهر
- فیلتر بر اساس وضعیت و پلن
- ایجاد و ویرایش اکانت
- فعال‌سازی، تعلیق و مسدودسازی اکانت
- حذف نرم با وضعیت `BLOCKED`
- تغییر پلن و تمدید اشتراک
- مشاهده وضعیت پرداخت و تاریخ انقضا
- مشاهده دامنه‌ها و وضعیت تأیید آن‌ها
- مشاهده وضعیت اتصال پیامک
- مشاهده گزارش فعالیت tenant

### رابط کاربری

- داشبورد RTL برای مدیر پلتفرم
- کارت‌های خلاصه وضعیت اکانت‌ها
- toolbar جست‌وجو و فیلتر
- لیست responsive اکانت‌ها
- صفحه ورود مرکزی و استاندارد برای مدیر
- مرحله جداگانه برای فعال‌سازی اولیه MFA
- جلوگیری از overflow شدن URI و کدهای طولانی MFA
- proxy مسیرهای `/platform/*` در Vite به API

## داده‌های تست

اسکریپت زیر برای ساخت داده‌های دمو اضافه شده است:

```bash
npm run seed:platform-demo
```

این seed یک مدیر توسعه و پنج کلینیک نمونه با وضعیت‌های فعال، تعلیق‌شده و مسدودشده ایجاد می‌کند. اجرای مجدد seed، نشست‌ها و MFA مدیر دمو را برای راه‌اندازی مجدد محیط تست reset می‌کند.

اطلاعات رمز عبور و کلیدهای MFA در این گزارش ثبت نمی‌شوند و فقط در محیط محلی نگهداری می‌شوند.

## فایل‌های مهم

- `apps/api/src/platform/platform-routes.ts`: routeهای ورود MFA و مدیریت اکانت‌ها
- `apps/api/src/server.ts`: ثبت routeهای پلتفرم
- `apps/api/src/index.ts`: اتصال دیتابیس پلتفرم و MFA
- `apps/web/src/platform/PlatformAdminPage.tsx`: صفحه مدیریت پلتفرم
- `apps/web/src/platform/platform.css`: استایل پنل و صفحه ورود مدیر
- `apps/web/vite.config.ts`: proxy مسیرهای API
- `packages/db/prisma/schema.prisma`: مدل‌های tenant، اشتراک، دامنه، پیامک و MFA
- `packages/db/prisma/migrations/20261101010000_platform_admin_panel/migration.sql`: توابع privileged پلتفرم
- `scripts/seed-platform-demo.ts`: داده‌گذاری دمو

## موارد باقی‌مانده

1. تکمیل مدیریت دامنه از داخل پنل، شامل افزودن دامنه و شروع verification.
2. تکمیل اتصال واقعی providerهای پیامک و تست ارسال پیامک tenant.
3. بررسی نهایی نمایش وضعیت SMS در نقش `hmn_platform` در کنار RLS.
4. اضافه کردن صفحه گزارش‌های تجمیعی پلتفرم و نمودارهای درآمد/مصرف.
5. اتصال پرداخت واقعی و ثبت invoice به‌جای وضعیت اشتراک فعلی.
6. افزودن تست UI برای login، MFA، فیلترها و لیست اکانت‌ها.
7. تعریف فرآیند commit، push و CI برای ریپوی GitHub.

## روش اجرای محلی

```bash
npm ci
npm run build
npm run dev --workspace @hmn/api
npm run dev --workspace @hmn/web
```

قبل از اجرای API، PostgreSQL و Redis محلی باید فعال باشند و فایل `.env` در ریشه پروژه وجود داشته باشد.
